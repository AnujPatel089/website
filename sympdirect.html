Business Understanding

Why This Problem Needs More Than a Prediction

Emergency intake combines symptoms, vitals, demographics and clinician notes under time pressure. SympDirect separates ML prediction from safety escalation and final clinician judgment so the workflow remains transparent and reviewable.

Review First

Free-text extraction returns evidence and missing fields and explicitly requires clinician review before prediction.

Safety Layer

Configured red flags—including oxygen saturation below 92%, altered consciousness, cardiopulmonary cues, severe bleeding and pregnancy with bleeding—can escalate routing to ESI 2.

Traceability

Predictions, clinician actions, audit events and official PDF reports are persisted server-side instead of living only in browser state.

Architecture & Implementation

Backend and Database as the Source of Truth

The public demo repository uses a React + TypeScript frontend connected to a FastAPI backend by default. SQLAlchemy persistence stores assessments, predictions, reviews, audit logs and report records. The ML serving layer validates model artifacts and feature contracts before inference.

Backend / DevOps Evidence

What the Repository Actually Implements

Live Backend Surface

Health/readiness, NLP extraction, prediction, assessment CRUD, clinician review, dashboard summary, report generation/download, audit retrieval and speech transcription endpoints.

Model Reliability

The model loader verifies required files, class labels and feature counts. The prediction service checks exact feature alignment and returns an explicit placeholder contract if the model is unavailable.

Automated Validation

GitHub Actions runs Python tests plus frontend tests/build. The demo-freeze reports 96 passing backend tests, 14 frontend test files with 52 passing tests, a passing React production build and a passing Docker Compose full-stack run.

Docker Demo Workflow

docker compose up --build starts FastAPI on port 8001 and React on port 5173, with named volumes for SQLite demo data and generated PDF reports.

Production Boundaries

The repo correctly labels itself as portfolio/educational decision support. Production use would still require clinical validation, real authentication/RBAC, PostgreSQL, managed secrets, privacy/security controls, centralized observability and governance.
