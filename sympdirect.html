SympDirect — AI-Powered Emergency Department Triage

Healthcare AI decision-support system designed to classify emergency-department encounters into Emergency Severity Index (ESI) levels 1–5 using large-scale clinical data, ML experimentation, backend integration and deployment-oriented engineering.

The Problem

Emergency departments must prioritize patients rapidly based on clinical urgency. SympDirect explores how machine learning can support this workflow by predicting ESI categories from structured ED data. It is decision support, not a replacement for clinical judgment.

Clinical Context

ESI ranges from 1 for the most urgent cases to 5 for lower-acuity encounters.

Engineering Challenge

Build reproducible preprocessing, model evaluation, API-ready inference and clean application integration.

Evaluation Mindset

Accuracy alone is insufficient; class-level recall, precision, F1 and confusion patterns matter.

Dataset & ML Workflow

The capstone uses a Kaggle emergency-department dataset with approximately 366,000 records and ESI labels 1–5, following CRISP-DM.

Data Pipeline

  • Schema and quality checks
  • Missing-value and feature preprocessing
  • Train/validation/test separation
  • Class-aware evaluation
  • Reusable inference transformations

Risk Controls

  • Avoid preprocessing leakage
  • Keep evaluation data isolated
  • Track class imbalance
  • Validate inference inputs
  • Separate experiments from serving code

System Architecture
