# Anuj Patel Portfolio

## Overview

Personal portfolio website for Anuj Patel, a software engineer and AI/ML enthusiast. The site presents a responsive profile, skills, featured machine learning projects, contact links, and a downloadable resume.

## Features

- Responsive single-page portfolio layout
- Fixed navigation with smooth scrolling
- Mobile hamburger menu
- Hero section with profile image and call-to-action buttons
- About, skills, projects, and contact sections
- Project cards with GitHub and live demo links where available
- Resume PDF link in the footer

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Static assets: PNG, JPG, PDF

## Installation

Clone or download the project files:

```bash
git clone <repository-url>
cd website-main
```

No package installation is required.

## Usage

Open `index.html` directly in a browser:

```bash
start index.html
```

Alternatively, serve the folder with any static file server.

## Folder Structure

